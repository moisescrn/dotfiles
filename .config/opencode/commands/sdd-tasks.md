following the format of the sdd skill:
- Small tasks (max. 20-30 min each), in dependency order
- Each one with the functional requirements (FR) it covers and a verifiable "Done when:" line
- Checkboxes
- Try to keep them to no more than 10: if there are more, propose splitting the spec
